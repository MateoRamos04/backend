# Backend de Aplicaciones - Bloque de contenidos 02

## Contenido del bloque

Materiales en este bloque de contenidos:

- Introducción a la plataforma Java en general, una introducción al esquema de funcionamiento de java y los diferentes componentes a descargar e instalar en un equipo de desarrollo
- Introducción a Maven como herramienta de gestión de plantillas de proyectos, dependencias, construcción y despliegue. Instalación y componentes principales.
- Revisión de la sintaxis de Java
