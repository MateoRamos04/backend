# Bloque 03

Materiales incluidos en el tercer bloque de contenidos, en este bloque cubrimos:

- Introducción a la programación orientada a objetos con Java
  - Introducción a la construcción liviana de objetos con lombok

- Revisión del uso de Vectores en Java y del Manejo de Excepciones en Java
- Testing unitario con Java y JUnit
